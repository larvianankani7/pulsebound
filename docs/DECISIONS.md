# Locked project decisions

- Product name: SYLVARA
- Tagline: Every meal uncovers a tale, and every tale opens a new world.
- Frontend-only; no backend at any stage in the agreed baseline.
- Five main sections: Findings, Explore, Learnings, Settings, About.
- Illustrated 2D garden + modern dashboard.
- Meal input: free text and searchable catalogue.
- Learning progression: discover an item → unlock lesson/quiz.
- Desktop and mobile have equal priority.
- Initial languages: English and Hindi.
- Findings avoids calorie counts, macro counts, numerical nutrition scores and daily targets.
- Quiz: exactly three questions, one attempt per unlock.
